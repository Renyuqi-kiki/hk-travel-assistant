一个问题，会经过哪些步骤？

你的问题→MCP 本地检索工具→官方资料片段→回答与出处

本地演示用关键词检索和资料摘录作答。配置模型后，RAG（检索增强生成）会把查到的片段交给大模型组织回答；它仍需要核对来源。

MCP（模型上下文协议）是应用调用工具的一种标准方式。这里的问答与规划确实通过本机 MCP 子进程通信；高德则使用官方远程 MCP 接口，需你自行配置 Key。

行程采用“按街区分组、按兴趣选点、再估算转场余量”的规则，不宣称找到最优路线。地图是地点方位示意，实时导航请打开地图服务核实。

之后接入真实服务

  1. 把项目根目录的 .env.example 复制为 .env。
  2. 只在本机填写模型服务与高德 Key，重启应用。不要把密钥发到聊天或上传仓库。
  3. 问答页勾选“使用大模型回答”；地点卡可测试“高德查询”。

未接通真实服务之前，不能将这个演示描述为已完成真实模型与高德端到端验证。没有密钥也可以演示检索、规划、引用、下载和本地 MCP 调用。
